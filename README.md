# Kaizen 改善 – site web

Pilote ton dressing Vinted depuis ton téléphone ou n'importe quel PC.
Le site envoie des ordres à l'extension **Kaizen** installée dans Chrome sur ton ordinateur ;
c'est elle qui agit sur Vinted, avec ta propre connexion (jamais envoyée au site).

- Accueil : état du PC (en ligne / hors ligne), activité, compteurs du jour, actions rapides.
- Annonces : liste, recherche, filtres, sélection → republier, masquer, afficher, baisser le prix.
- Auto : planification, offres, messages automatiques, baisse de prix, après-vente, prudence.
- Ventes : chiffre d'affaires, marges, graphiques, dernières ventes.
- Plus : historique, messages programmés, ordres envoyés, compte (déconnexion, suppression).

Installable sur l'écran d'accueil du téléphone (« Ajouter à l'écran d'accueil »).

Mise en ligne : voir `MISE-EN-LIGNE.md`. Contexte technique : `CLAUDE.md`.

Kaizen est un outil indépendant, non affilié à Vinted.
